**No More Room in Hell 2's official minimum specs call for a GTX 760-class GPU, an quad-core CPU and 8 GB of RAM, with 25 GB of free storage.** The requirements below were published around the early access launch and still describe the 1.0 build's baseline, though the game has grown heavier with every map added.

## Minimum requirements

| Component | Specification |
|-----------|---------------|
| OS | Windows 7 64-bit |
| CPU | Intel Core i5-4460 or AMD FX-6300 or better |
| RAM | 8 GB |
| GPU | NVIDIA GeForce GTX 760 or AMD Radeon R7 260X 2 GB |
| DirectX | Version 11 |
| Storage | 25 GB available space |

## Recommended requirements

| Component | Specification |
|-----------|---------------|
| OS | Windows 10 64-bit |
| CPU | Intel Core i7-3770 or AMD FX-9590 or better |
| RAM | 8 GB |
| GPU | NVIDIA GeForce GTX 970 or AMD Radeon RX 470 4 GB |
| Storage | 30 GB available space |

## What this means in practice

The spec sheet is friendly to older PCs because the game targets console-class parity hardware — the same baseline carries the Xbox Series S build. Two caveats worth knowing:

1. **The engine is UE5.** No More Room in Hell 2 moved from the original's Source engine to Unreal Engine 5, and while the requirements look modest, framerate dips in dense horde fights are the most common complaint on minimum-spec machines.
2. **Storage keeps growing.** Every map added since early access — Broadway, Beaulieu, Hospital, Raven Rock, Pottsville, Lewiston — pushes the install closer to the 30 GB recommended figure. Keep headroom.

If you are upgrading a setup specifically for this game, an SSD and a GPU a tier or two above the recommended card will smooth out the streaming-heavy open maps.
